# Chihuahua Community Engine

This tool helps you make Chihuahua images and short videos.

You do not need to know prompting.

Tell it what Chihuahua is doing. The Engine handles the rest.

## Install

You need a paid ChatGPT plan; Personal Skills are not available on Free or Go. Install from chatgpt.com in a browser. If you also use the desktop app, add the Skill there separately.

1. Download [chihuahua-community-engine.zip](https://github.com/nosimajtechnology/chihuahua-community-engine/releases/latest/download/chihuahua-community-engine.zip). **Do not unzip it.**
2. In ChatGPT, open **Plugins** from the sidebar, then **Skills** → **Create** → **Upload from your computer**, and pick the zip.
3. Start a new **Chat** or **Work** session.

Use this as your first prompt:

```
Load the "Chihuahua Community Engine" skill.
```

## Start

After it loads, type one normal sentence:

```
Make an image of Chihuahua managing a cheap motel.
```

Pictures are made in the chat. For video, the Engine writes the prompt and you paste it into your video model (see **Animate** below).

## Choose a mode — or do not

- **IMAGE** — one picture
- **MINI** — quick animated moment
- **SCENE** — short cinematic
- **BUMPER** — short loop
- **FAKE AD** — fictional commercial

You can name a mode, or let the Engine choose.

## Approve

For videos, the Engine may first make a starting image.

If it looks right, reply:

> Approved.

The Engine will keep that Chihuahua, outfit, place, and game style consistent.

It may then make a storyboard. If the order looks right, reply:

> Storyboard approved.

## Animate

Tell it which video model you use:

> Seedance 2.

or:

> Kling.

If you are not sure, say:

> Not sure. Give me a general video prompt.

## Fix a mistake

Use normal words:

> He has four legs. Fix only that.

> His face changed. Keep everything else.

> This looks too modern.

The Engine will make a narrow repair prompt.

That is all you need to start.
