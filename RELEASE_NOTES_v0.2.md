# Chihuahua Community Engine v0.2

The first community release.

## Included

- The installable Chihuahua Community Engine Skill
- The authoritative Chihuahua character reference
- IMAGE, MINI, SCENE, BUMPER, and FAKE AD modes
- Storyboard and animation workflows
- Seedance, Kling, and model-neutral prompt support
- Narrow repair instructions for common generation mistakes
- Simple mobile and desktop installation guides
- Community guide, example ideas, release post, and quick command card

## Install

*These are the v0.2 steps as shipped. The current install is three steps — see the [README](./README.md).*

Download `CHIHUAHUA_COMMUNITY_ENGINE.zip`.

Unzip the full package, but leave `1_INSTALL_CHIHUAHUA_ENGINE.zip` zipped. Upload that inner ZIP from **ChatGPT → Plugins → Skills → Create → Upload from your computer**.

Start a new Chat or Work session with:

> Load the “Chihuahua Community Engine” skill.

Then tell it what Chihuahua is doing.
