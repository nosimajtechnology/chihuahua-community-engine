# SCENE — Night Security

## Try this

> Make a SCENE where Chihuahua is working overnight security in an empty shopping mall. He notices something moving in the distance and slowly leaves the security desk to investigate.

## Easy changes

- Use a warehouse instead of a mall.
- Make the mall bright and strangely empty.
- Have Chihuahua discover something harmless and ridiculous.
- End before the reveal for a more mysterious scene.

Use **SCENE** when you want a short cinematic with progression across multiple shots.
