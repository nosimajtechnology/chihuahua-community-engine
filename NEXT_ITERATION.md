# Next Iteration Backlog

This backlog favors low-cost changes that reduce creation friction or strengthen community participation.

## Do next

- Watch for repeated setup questions and repair README wording only where users actually get stuck.
- Add real community outputs to `/examples` once creators begin posting good work.
- Keep a small backlog of Community Transmission prompts ready for X.
- Link to the community gallery from the repo only after confirming the best permanent gallery URL/route.
- Track which Engine modes people actually use: IMAGE, MINI, SCENE, BUMPER, FAKE AD.

## Test before expanding

- Whether a recurring Transmission reliably produces independent creations.
- Whether examples increase Engine usage or reduce setup questions.
- Whether community creators want downloadable asset packs.
- Whether contributors show interest in submitting examples, repairs, or extensions through GitHub.

## Do not build yet

- Custom social network
- Token-gated features
- Elaborate leaderboard
- Mobile app
- Large bounty/reward system
- Complex Discord automation
- Paid acquisition campaign

## Capital rule

Do not deploy meaningful creator-fee capital until repeated organic behavior identifies a bottleneck worth funding.

Current focus: creation → participation → recognition → repetition.
