# IMAGE Mode

Use IMAGE for one finished picture. Keep it the first and lowest-friction mode.

## Default behavior

1. Read the idea as an ordinary scene, not as a technical form.
2. Choose one clear composition, outfit, location, mood, and old-game build.
3. Use `references/chihuahua-character-sheet.png` as the canonical Chihuahua
   identity authority.
4. Generate one image when generation is available.
5. Invite a narrow repair, variation, or scene continuation.

Do not automatically create a storyboard, shot list, animation prompt, or
motion brief.

## Image direction

When the idea is clear, give one concise direction and generate immediately.
Example:

> Best fit: IMAGE. Chihuahua sits behind the counter of a cramped early-2000s
> pawn shop, surrounded by old televisions, jewelry cases, and cheap
> electronics. He wears an oversized button-up shirt and stares directly at the
> camera.

When the user asks for options or the idea needs development, offer no more
than three compact directions. Each direction needs one main visual, not a
story synopsis.

## Composition

Default to:

- one immediately readable subject and action
- 4:3 historical framing when appropriate
- a practical in-game camera
- enough environment to explain the situation
- no embedded text, caption, HUD, logo, or watermark unless requested
- no unrelated token or crypto imagery

Use portrait, square, or widescreen delivery only when requested or clearly
needed for a cover, profile image, wallpaper, or platform format.

## Prompt order

Build the image prompt in this order:

1. exact scene and action
2. master-reference identity lock and bipedal rule
3. current outfit and props
4. environment and spatial arrangement
5. selected console build and approximate year
6. geometry, texture, lighting, shadow, and rasterization behavior
7. camera, crop, and composition
8. expression and small action detail
9. decisive negative constraints

## Variations

When the user asks for variations, preserve identity and change only the named
layer:

- alternate angle
- alternate pose or expression
- alternate clothing
- alternate location
- alternate time of day
- 2-4 concept variants

Do not treat a variation request as permission to modernize the build or change
the face.

## Continue into video

When the user says `turn this into a scene`, `animate this`, or equivalent:

1. treat the approved image as identity, wardrobe, environment, lighting,
   palette, rendering, and start-state authority
2. keep the canonical character sheet as background identity support
3. do not regenerate the approved image
4. route to MINI, SCENE, or BUMPER based on the intended action
5. create the next artifact from the approved image

If intent is unclear, choose MINI for one tiny action and SCENE for progressive
action. Ask only if the difference materially changes the user's goal.
